# Sources for on-screen facts

Facts added or corrected from November 2026 onward are listed here with the source that was read (the page was opened and the claim found on it). Facts written before that date are not all sourced yet; they are being re-checked a batch at a time.

Rules for new facts: one sentence, at most 140 characters, plain language. Prefer a conservative wording we can confirm over a bigger number we cannot. If a claim has no page we have read, it does not ship.
